# The price read goes through MCP

The support agent's server reads Monitor Pangan only through MCP. The model never holds that credential and never performs the price read. Visitor text does not cross it. One tool returns the price table for a commodity and a trading date. The server then picks a province, ranks, or compares. The raw message is never an argument. The web chat and the CLI both go through that server.

The model calling MCP, the browser speaking MCP, and fetching Monitor Pangan directly were rejected. A direct fetch is the shortcut a participant's coding agent will take unless the boundary is the product.
